**String Art Studio Pro v9.0** — профессиональная студия и высокоточный алгоритмический комплекс для создания картин в технике **String Art** (изонить / филография) из непрерывной нити на основе математических методов томографии и эволюционного моделирования.

---

## 🌟 Ключевые возможности v9.0

### 1. 🏝 Островная модель генетического алгоритма (Island GA)
* **Параллельная многопоточная эволюция**: популяции развиваются независимо на отдельных вычислительных островах (`IslandThread`), обмениваясь элитными мигрантами с настраиваемым интервалом.
* **Графовые операторы мутации высокого порядка**:
  * **Smart Hinge** — локальное шарнирное перемещение гвоздя с пересчетом локальной невязки оптической плотности;
  * **Radon Bridge** — топологический мост с использованием матриц смежности синограммы Радона;
  * **2-Opt Invert** — инверсия связных подпоследовательностей пути нити;
  * **Jitter Pin** — фазовый микросдвиг соседних гвоздей.
* **Меметическая оптимизация**: координатный дельта-спуск для субмикронной полировки пути без застревания в локальных минимумах.

### 2. 📊 Живая аналитика и динамические графики Matplotlib
* **Кривая сходимости (Convergence Curve)**: отображение кривых фитнеса для каждого острова в реальном времени с пунктирной линией базового уровня OMP-синтеза.
* **Гистограмма КПД операторов мутации (Mutation KPI)**: горизонтальная столбчатая диаграмма реальной результативности каждого мутатора (*Smart Hinge*, *Radon Bridge*, *2-Opt*, *Jitter Pin*).
* **Светлое оформление графиков**: гармоничная интеграция в современный светлый интерфейс студии.

### 3. 👁 Визуализация процесса в реальном времени (Real-Time Canvas)
* **Прогрессивная отрисовка OMP-синтеза**: картина отображается на холсте прямо в процессе генерации (каждые 25 нитей и на каждом шаге для первых 30 нитей) — мастер видит, как штрих за штрихом рождается портрет.
* **Живое обновление эволюции**: каждое улучшение хромосомы немедленно визуализируется через выделенный поток рендеринга с интеллектуальным сбросом устаревших кадров (*Frame Dropping*), гарантируя плавность интерфейса.
* **Специализированные аналитические экраны**:
  * `★ Лучший результат` — чистовой рендер картины с 4x SSAA;
  * `Остров 1..4` — визуализация решений каждого острова;
  * `Карта Ошибок (Кр/Син)` — красно-синяя матрица отклонения оптической плотности;
  * `Плотность нитей (Heatmap)` — карта локального перенасыщения волокон;
  * `Карта Значимости (DoG)` — разность гауссианов и взвешенные контуры лиц и глаз;
  * `Синограмма Радона (FBP)` — томографическая проекция лучевых интегралов.

### 4. ✨ Выделенная кнопка «Эволюционная доводка»
* Возможность запустить параллельный островной генетический алгоритм **на текущей нити без перезапуска OMP-синтеза**.
* Позволяет продолжать совершенствовать детали картины в несколько этапов, меняя на лету параметры мутаций и веса контуров.

### 5. ☀️ Чистая современная светлая тема (Light Theme)
* Полный редизайн интерфейса в светлых тонах:
  * Фон приложения: `#f6f8fa`
  * Холсты и карточки: `#ffffff`
  * Акцентный цвет: `#0969da`
  * Текст и метки: `#1f2328`
  * Шрифты: Segoe UI с выверенной типографикой.

### 6. 🌀 Преобразование Радона и фильтр Рама-Лака (FBP)
* Вычисление синограммы интегральных проекций по направлениям углов.
* Фильтрация проекций высокочастотным рамповым фильтром Рама-Лака ($|\omega|$) в частотной области Фурье.
* Наведение нитей по синограмме Радона исключает образование темной "каши" и сохраняет черты лица и мелкие детали.

### 7. 🔊 Голосовой и интерактивный ассистент сборки
* **Windows SAPI Голос**: встроенное голосовое озвучивание номеров целевых гвоздей для работы обеими руками без экрана (*"на 142"*, *"на 89"*).
* **Интерактивный скраббер**: просмотр плетения от 1-й до последней нити с неоновой подсветкой активного хода.
* **Шторка сравнения "До / После" (Split Compare)**: динамическое сопоставление исходного фото и картины нитями прямо поверх холста.

### 8. 🌐 Автономный интерактивный веб-ассистент (.html)
* Экспорт автономного HTML5-файла со встроенной базой гвоздей, голосовым синтезом Web Speech API, горячими клавишами и сохранением прогресса в `localStorage`.

### 9. 📦 Полный комплекс экспорта
* **.txt** — пошаговая карта плетения с точным расчетом расхода нити в метрах.
* **.png Ultra HD** — печатный мастер-растр сверхвысокого разрешения (до 2400x2400px) с 4x SSAA сглаживанием.
* **.svg** — масштабируемый векторный чертеж.
* **.html** — автономный веб-помощник для планшета и смартфона.

## 🚀 Быстрый запуск

### Требования
* Windows 10 / 11, Linux или macOS
* Python 3.10 – 3.13 (x64)

### Установка зависимостей
```bash
pip install -r requirements.txt
```

### Запуск
* **Windows (в 1 клик)**: дважды кликните по файлу `run_studio.bat`
* **Командная строка**:
```bash
python string-art-generator.py
```
