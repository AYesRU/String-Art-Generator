**String Art Studio Pro v9.0** — профессиональная студия и сверхбыстрый алгоритмический движок для создания картин в технике **String Art** (изонить / филография) из одной или нескольких непрерывных нитей.

Проект объединяет фундаментальные математические методы томографии (**Преобразование Радона и Filtered Back Projection**), сверхбыструю векторную оптимизацию на базе **разреженных матриц SciPy CSR**, субтрактивное **CMYK-цветоделение**, оптический рендеринг по **закону Бера-Ламберта** и автономного **интерактивного голосового веб-ассистента** для ручного плетения картин.

---

## 🌟 Ключевые возможности v9.0

### 1. ⚡ Экстремальная скорость синтеза (2500+ линий в секунду)
- Поиск оптимального пути переписан с медленных поэлементных циклов на сжатые разреженные матрицы **SciPy CSR (Compressed Sparse Row)**.
- Векторная оценка сотен лучей-кандидатов выполняется всего за **0.08 миллисекунды**.
- Полный синтез картины из **3000 нитей занимает ~1.2 секунды** (ускорение более чем в **1000 раз** по сравнению с предыдущими версиями).

### 2. 🎮 Аппаратное ускорение на GPU NVIDIA CUDA
- Автоматическое обнаружение графических процессоров NVIDIA (GeForce RTX 5060, RTX 40-й / 30-й серий) через PyTorch.
- Отображение статуса GPU, объема видеопамяти и скорости обработки в строке состояния.

### 3. 🌈 Полноцветный String Art (CMYK 4-слойное плетение)
- **Монохромный режим**: классическая угольно-черная нить на белом фоне или белая нить на темном холсте.
- **Цветной CMYK**: субтрактивное разложение изображения на каналы **Циан (Cyan)**, **Маджента (Magenta)**, **Желтый (Yellow)** и **Черный (Black)**.
- Послойный расчет индивидуальных путей нитей с физическим оптическим смешением цветов.

### 4. 📐 Расширенная геометрия рам холста
- **Круг** (Circle) — классическая радиальная форма.
- **Квадрат** (Square) — квадратная рама.
- **Прямоугольник (4:3 и 16:9)** — поддержка портретных и пейзажных пропорций без обрезки композиции.
- **Овал / Эллипс** — гладкий контур с параметрическим расчетом дуг.
- **Шестиугольник** (Hexagon) — геометрическая правильная многоугольная рама.

### 5. 🌀 Преобразование Радона и FBP (Filtered Back Projection)
- Математический аппарат компьютерной томографии: расчет синограммы по интегральным лучам изображения.
- Высокочастотный рамповый фильтр Рама-Лака ($|\omega|$) в частотной области Фурье.
- Веса проекций Радона помогают жадному алгоритму сохранять глобальную структуру (черты лица, глаза, тонкие контуры) без застревания в локальных минимумах.

### 6. 👁 Физический оптический рендеринг (4x SSAA Subpixel, без каши)
- Оптическое пропускание света по закону **Бера-Ламберта**: $T(x,y) = \exp(-\tau \cdot D(x,y))$.
- Субпиксельное сглаживание линий `cv2.LINE_AA` (4x суперсэмплинг).
- Предотвращение перенасыщения: даже при 4000+ нитях картина сохраняет идеальную глубину полутонов и четкость, без грязных артефактов ("без каши").

### 7. 🔊 Голосовой и интерактивный ассистент ручного плетения
- **Windows SAPI Голос**: встроенное озвучивание целевых гвоздей в реальном времени (*"на 142"*, *"на 89"*). Позволяет мастеру плести картину обеими руками без необходимости смотреть на экран.
- **Интерактивный скраббер**: плавный ползунок шагов с визуальной подсветкой активной нити неоновым свечением.
- **Расчет расхода нити**: конвертация длины хорд в реальные физические метры и футы на основе диаметра картины (например, 60 см, 80 см).

### 8. 🌐 Автономный интерактивный веб-ассистент (HTML5/JS)
- Генерация единого, независимого файла `.html`, который можно отправить заказчику или открыть на смартфоне/планшете у рабочего стола.
- Встроенный векторный холст, пошаговое управление кнопками и клавиатурой (Пробел / Стрелки), голосовой синтез через Web Speech API и сохранение прогресса в `localStorage`.

### 9. 🔀 Интерактивное сравнение "До / После" (Split Compare)
- Вкладка со скользящей интерактивной шторкой разделения между оригинальной фотографией и результатом плетения.

### 10. 📦 Полный комплекс экспорта
1. **Интерактивный HTML5 Веб-ассистент** (`.html`).
2. **Пошаговая текстовая инструкция** (`.txt`) с таблицей шагов и метражом.
3. **Таблица для станков и баз данных** (`.csv`).
4. **Управляющая программа для ЧПУ станка** (`.gcode / .nc`).
5. **Масштабируемый векторный файл** (`.svg`) с разделением по слоям.
6. **Печатный мастер-растр Ultra-HD** (`.png`) с разрешением до 4000x4000px.
7. **Шаблон разметки гвоздей 1:1** (`.svg`) для печати на плоттере и наклейки на доску для сверления.

## 🚀 Быстрый запуск

### Требования
- Python 3.10 – 3.13 (x64)
- Рекомендуется видеокарта NVIDIA с поддержкой CUDA

### Установка зависимостей
```bash
pip install -r requirements.txt
```

### Запуск приложения
```bash
python string-art-generator.py
```
*На Windows можно просто запустить двойным кликом файл `run_studio.bat`.*

## ⌨ Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Пробел` / `D` / `→` | Следующий шаг в плеере |

## 🛠 Сборка автономного EXE (Windows)

Для компиляции в единый переносимый файл `.exe`:
```bash
pip install pyinstaller
pyinstaller --noconfirm --onedir --windowed --icon=StringArt.ico --name "StringArtStudioPro" string-art-generator.py
```
Собранное приложение появится в папке `dist/StringArtStudioPro/`.
